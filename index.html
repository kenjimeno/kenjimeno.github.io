QR Code Based Student ID Verification System for City College of Tagaytay

A QR-based student entry system designed to provide a secure and efficient way of managing student access. The system generates a unique QR code for registered students through a mobile application and verifies it using an embedded QR scanner before allowing access through a turnstile gate. It integrates software, database, and hardware components to provide real-time student verification and controlled entry.

Technologies used:
